# Rudy RouteAtlas 0.1.0 preview

Offline C++20 BGP origin validation and VRP snapshot comparison for IPv4 and IPv6. The JSON report records coverage, origin and length decisions, witness VRPs, and a transition matrix. The optional regression gate supports CI.

Windows x64, Linux x64, and macOS ARM64 packages include the native binary, build documentation, and a runnable synthetic example. Verify each archive against its SHA-256 manifest entry.
